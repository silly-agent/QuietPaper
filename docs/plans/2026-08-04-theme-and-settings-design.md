# Quiet Paper 主题与设置页设计

## 目标

让主题从大面积同色染色改为耐看的中性表面体系，同时把当前纵向堆叠的设置内容拆成清晰的左侧 Tab 页面。

## 视觉方案

每套主题继续保留自己的强调色，但强调色只用于选中态、主按钮、焦点、状态图标和低透明度点缀。大面积表面改用低彩度中性色：编辑器最接近纯净纸面，侧栏与列表栏用轻微冷暖倾向和明度差建立层级，工具与卡片表面位于两者之间。正文、辅助文字和分隔线继续使用 macOS 语义色，保证浅色与深色外观中的可读性。

“暖纸、森林、深海、樱花、午夜”的个性主要由强调色和极轻微的表面色温表达，不再让整个窗口覆盖明显的黄、绿、蓝、粉或紫色。系统主题仍直接使用系统表面与系统强调色。

## 设置结构

设置面板采用左侧导航、右侧内容的双栏结构。左侧固定提供“外观、AI、存储、最近删除、关于”五个 Tab；右侧只展示当前页面，并由页面自行决定是否滚动。右上角保留“完成”按钮。

“外观”页面用预览卡同时展示侧栏、编辑器和强调色的关系；“AI”保留密钥、模型与索引管理；“存储”保留目录展示与迁移；“最近删除”保留恢复和永久删除；“关于”展示版本、本地优先和隐私说明。页面切换不重建 AppModel，也不改变现有持久化流程。

## 安全与验收

主题切换继续即时写入 UserDefaults。存储迁移与最近删除沿用现有操作入口，不在实现或测试中访问、删除或重置正式数据库。验收覆盖 Swift 编译、现有内存数据库测试，以及浅色和深色模式下的主题和设置页视觉检查。
