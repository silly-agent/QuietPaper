# Quiet Paper 文件列表排序设计

## 目标

在中间文件列表标题栏右侧增加紧凑的二级排序菜单，默认按文件名正序，并允许按创建时间或修改时间以及正序、倒序组合排序。

## 交互

把排序入口从副标题移到标题栏右侧，使用排序图标、当前字段和方向组成紧凑控件。菜单内分组显示排序字段和方向，菜单项显示勾选状态，切换后列表立即刷新并将选择保存为本地应用偏好；首次使用默认文件名正序。

文件名使用本地化自然顺序，空标题按“未命名笔记”参与排序。创建时间和修改时间按所选方向排序，主字段相同再按文件名和 UUID 作为稳定的次级排序。搜索状态下继续按搜索相关性展示结果，不套用普通文件排序。

## 实现边界

排序在内存中的 `model.notes` 上完成，不修改 SQLite 查询、表结构或文件的 `sort_order`，也不改变用户的层级组织。排序状态只通过 UserDefaults 保存，不写入笔记数据。菜单使用中间列表标题栏右侧的紧凑控件，并沿用 Quiet Paper 的语义字号 / 主题色。

## 验收

验证默认入口显示文件名正序；三种字段和两种方向都能改变列表顺序并保持勾选状态；切换模块或重新渲染后选择仍然有效；搜索结果仍保持原有相关性排序；完整测试继续使用内存数据库。
