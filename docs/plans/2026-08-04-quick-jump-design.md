# Quiet Paper 一键跳转设计

## 目标

提供最多三个全局快捷页面：`Command + 1`、`Command + 2`、`Command + 3`。无论当前位于普通文件列表、请求编辑器、连接编辑器、专注模式或设置面板，触发快捷键后都跳转到对应文件。

## 页面指定方式

设置中新增“快捷跳转” Tab，每个快捷位提供两种指定方式：

1. 从菜单中直接选择任意项目 / 模块下的笔记、请求或连接文件。
2. 先打开目标文件，再点击“使用当前页面”绑定到该快捷位。

每个快捷位同时显示完整路径，未设置时显示“尚未设置”，原文件被删除时显示“原页面已不存在”。

## 状态与导航

快捷位只保存目标文件 UUID 到 UserDefaults，不修改笔记数据库。启动时不主动跳转；触发时由全局键盘监听器发送统一通知，RootView 交给 AppModel 导航。普通模块文件通过切换模块后选择文件，项目根目录文件通过项目文件导航，二者都先保存当前编辑内容。

## 边界

快捷页面以文件为单位，覆盖 Markdown 笔记、HTTP 请求和数据库连接；项目、模块本身不作为跳转目标。最多三个固定槽位，不提供自定义快捷键和第四个槽位。

## 验收

验证设置 Tab 可见三个快捷位；“选择页面”和“使用当前页面”都能保存；从另一文件触发 `Command + 1/2/3` 能切换到对应文件；项目根目录文件和模块文件都能跳转；原文件删除后快捷键安全无操作；搜索、专注模式和设置面板不影响快捷键监听。
