# Quiet Paper 批量删除设计

## 目标

在文件列表已通过 Shift 形成范围多选时，让右键菜单支持一次删除全部选中文件。批量删除沿用现有软删除语义：文件移入「最近删除」，不永久移除附件或数据库记录，可由用户恢复。

## 交互

右键点击范围内任一选中文件时，菜单底部显示“删除 N 个文件”；未形成有效多选或右键文件不在范围内时，继续显示单篇“删除”。点击批量删除后只出现一次系统确认框，标题为“删除 N 个文件？”，正文说明文件将移到最近删除并可恢复。确认后执行批量操作，成功后清空范围选择并由 AppModel 重新选择剩余文件。取消不改变选择或数据。

快速折叠继续保留在多选菜单顶部。重命名和移动仍针对右键所在的单篇文件，本次不扩展为批量操作，避免扩大功能范围。

## 数据与安全

WorkspaceDatabase 新增接受 UUID 数组的批量软删除 API。API 先去重，在单个 SQLite 事务中移除相关折叠组成员、写入统一的 `deleted_at` 时间、清理被删文件的全文索引与向量块；任一步失败都回滚，不允许只删除部分文件。单篇软删除复用同一内部实现，避免两套逻辑漂移。

所有自动化验证必须显式使用 `WorkspaceDatabase(inMemory: true)`。测试创建三篇虚构笔记，批量删除其中两篇，确认第三篇、搜索索引和向量块不受影响，确认折叠组被正确清理，并验证两篇均出现在最近删除且可以恢复。测试不解析或访问 `applicationDatabaseURL()`，不连接 `~/Library/Application Support/QuietPaper/quiet-paper.sqlite`。
