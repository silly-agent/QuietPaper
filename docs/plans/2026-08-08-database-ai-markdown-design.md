# 数据库 AI 对话 Markdown 设计

## 目标

数据库助手的 AI 回复不再显示原始 Markdown 标记，而是以紧凑、可选择的富文本呈现。支持应用现有 Markdown 能力：标题、粗体、斜体、行内代码、链接、无序列表、引用、分隔线、代码块与表格。

## 交互边界

- AI 正文和展开后的「思考过程」使用 Markdown 渲染。
- 用户消息与系统状态消息保持纯文本，避免用户输入被意外解释为格式或链接。
- 代码块保留语言标签、语法着色、横向滚动和复制按钮。
- 表格沿用笔记预览的横向滚动表格。
- Markdown 图片不自动读取网络；对话中只显示本地安全的图片占位信息，保持应用 local-first。
- 解析失败时回退为原始文本，不影响历史消息加载与数据库操作。

## 架构

新增一个紧凑的 `CompactMarkdownView`，消费现有 `MarkdownParser` 产出的块模型。笔记预览与聊天渲染共用内联 Markdown 转换器、代码块和表格视图，避免两套语法行为逐渐分叉。数据库消息模型和持久化格式不变，历史回复会自动获得新渲染效果。

## 验收

- `**2 个项目**` 显示为粗体，不展示星号。
- `` `projects` `` 显示为行内代码，不展示反引号。
- `- 项目` 显示为项目符号列表。
- fenced SQL/JSON 代码块使用等宽字体并可复制。
- 思考过程展开后同样支持 Markdown。
- 用户消息仍按原字符串显示。
- 自动检查使用内存数据库，不访问或修改正式数据库。
