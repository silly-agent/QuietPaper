# Quiet Paper 紧凑双栏设计

## 目标

把项目树与文件列表收敛成精致、低噪音的 macOS 导航界面。保持现有项目、模块、文件、排序、折叠与右键菜单能力不变，只重做密度、文字层级、图标对比度和选中反馈。

## 视觉方向

采用原生且克制的紧凑风格。项目栏中，项目名称使用 13pt medium，模块和项目文件使用 13pt regular；更小、更淡的图标只帮助辨认类型，不与标题争夺注意力。文件栏标题使用 13pt medium，时间使用 11pt regular 与等宽数字。两栏行内容控制在约 28–30pt 的视觉高度，标题栏减少上下留白。

选中态不再依赖大面积、圆润且颜色明显的胶囊背景，而是使用极浅的强调色底面配合左侧 2pt 短色条。悬停态只显示轻微的中性色底面。项目栏和文件栏共享这一视觉语法，但各自保留现有主题背景，保证不同主题和深色模式下仍有足够层次。

文件列表标题栏继续展示当前模块名称；排序按钮缩减为单图标，具体排序字段与方向保留在菜单和辅助功能描述中。新建入口保持单图标。折叠组沿用普通文件行的密度，只用细描边和强调图标表示其特殊状态。

## 边界与验证

本次不修改模型、数据库、排序算法、快捷操作或持久化。验证以 Swift 编译、现有内存数据库测试和 `--in-memory-preview` 启动检查为准，绝不访问用户正式数据库。
