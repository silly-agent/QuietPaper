# 编辑器头部控件视觉设计

## 目标

重新设计编辑器右上角的编辑、预览、专注模式与更多操作控件，降低灰色块和杂乱线条带来的视觉负担，同时保留现有功能、快捷键、提示文字与辅助功能语义。

## 视觉与交互

- 编辑与预览保留为一个紧凑分段控件，使用 `square.and.pencil` 与 `doc.text`，仅选中项使用低饱和主题强调色底和细描边。
- 专注模式从分段控件中独立出来，使用由 SwiftUI 绘制的四角取景框图标，避免斜向双箭头造成的噪声。
- 更多菜单使用无外圈的水平三点，隐藏系统追加的下拉箭头。
- 三类控件统一为 32pt 外部高度、8pt 圆角与一致线宽；普通状态透明，hover 时出现淡底和描边，按压时轻微缩小。
- 控件组之间保留 6pt 间距。工具提示、键盘操作和 VoiceOver 标签沿用现有语义。

## 边界与验证

只修改 `NoteEditorView` 的头部控件，不改变编辑/预览状态、专注模式通知、菜单动作、数据库或版本号。通过 `swift build` 和内存数据库测试脚本验证编译与回归。
