# Quiet Paper 文件列表快速折叠设计

## 目标

在中间文件列表中支持符合 macOS 习惯的 Shift 区间选择。用户先单击文件 A，再按住 Shift 单击文件 B，列表选中当前可见文件范围；右键任一已选文件可执行“快速折叠”。折叠后以单行“折叠 N 个文件”替代组内文件，点击该行时用平滑动画展开全部成员。

## 交互

普通单击只选中一个文件，同时更新编辑区并作为下一次 Shift 选择的锚点。Shift 单击在当前排序和当前可见文件列表中选择锚点到目标文件的闭区间，目标文件成为编辑区当前文件。区间选择使用比普通悬停更清晰、但比当前编辑文件稍弱的强调背景。

当至少选中两个文件时，已选文件的右键菜单显示“快速折叠（N 个文件）”。执行后隐藏成员并显示紧凑折叠行。若当前编辑文件属于该组，折叠行保持选中强调。点击折叠行立即展开并删除持久化组记录；搜索结果始终逐文件展示，不参与折叠。

## 数据与生命周期

新增 `note_fold_groups` 和 `note_fold_group_members` 两张 SQLite 表，以模块、组和文件 UUID 保存关系。折叠状态随现有数据库备份和存储目录迁移自然保留，不写入笔记正文，也不进入 FTS。

一个文件最多属于一个折叠组。组在当前排序下第一个成员的位置显示，因此用户切换排序后仍能得到自然位置。单个文件移到其他模块或移入最近删除时退出原组；组不足两个有效成员时自动解散。模块或项目软删除不会销毁组，恢复后折叠状态仍在；永久删除依靠外键级联清理。

## 验证

- 使用 `WorkspaceDatabase(inMemory: true)` 验证创建、读取、展开、移动与软删除清理。
- 验证 AppModel 创建和展开后立即刷新折叠状态。
- 构建应用并运行 `./scripts/run-tests.sh`，确认现有笔记、搜索、备份和自动保存路径无回归。
- 使用 `--in-memory-preview` 启动界面，人工验证 Shift 范围、右键菜单、折叠行与展开动画；禁止连接生产数据库。
