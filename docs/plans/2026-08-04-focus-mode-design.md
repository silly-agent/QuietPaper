# Quiet Paper 专注模式设计

## 目标

在 Markdown 编辑区右上角的“预览”按钮右侧增加“专注模式”按钮。点击按钮或按下 `Command + E` 时，同时隐藏左侧项目导航和中间文件列表，只保留编辑区；再次触发时恢复完整栏位。Markdown 文件在专注模式下使用居中的宽正文画布，并隐藏窗口级搜索 / AI 工具栏、笔记标题栏、编辑/预览控制、格式工具栏和状态栏，仅保留正文编辑区；请求和连接编辑器保持原有全宽布局。

## 状态与交互

专注模式是当前应用会话中的全局界面状态，不写入数据库，也不跨启动保存。`AppModel.isFocusMode` 是按钮、菜单命令和快捷键共享的唯一状态源；开启时 `RootView` 直接渲染编辑区，关闭时恢复原来的 `NavigationSplitView`。不依赖 macOS 上不稳定的 `.detailOnly` 栏位请求，因此同时兼容项目直属文件的两栏结构，以及模块文件的三栏结构。

按钮使用独立的四角取景框图标，放在编辑 / 预览分段控件右侧。进入专注模式后按钮使用主题强调色，并通过提示文字显示“退出专注模式（⌘E）”。快捷键由现有本地键盘监听器接管，避免与 macOS 默认的 `Command + E` 菜单动作冲突。

如果用户在专注模式中按 `Command + B`，应用先退出专注模式并恢复全部栏位，避免按钮状态与实际栏位可见性不一致。普通模式下 `Command + B` 保持现有行为。

专注模式正文画布采用响应式宽度：最大宽度为 1280pt，窗口较窄时左右各保留至少 32pt 安全边距，并始终严格居中。窗口、正文和滚动区域统一使用纯白底色，不再绘制纸张边框或灰色侧翼；专注模式固定采用浅色阅读外观，以保证白底上的文字和语义色清晰可读。该布局只由 `NoteEditorView` 使用，因此不会改变 HTTP 请求和数据库连接工作台的宽度。

## 验收

使用内存数据库预览验证：三栏进入专注后仅保留正文编辑区，再次触发恢复三栏；Markdown 文件的窗口级工具栏、标题栏、格式工具栏和状态栏均隐藏，宽正文画布居中、左右留白对称且全窗纯白；请求和连接编辑器不套用该宽度；两栏进入专注后只保留编辑区，再次触发恢复两栏；`Command + E` 可以交替切换；`Command + B` 不会留下错误的专注状态。完整自动测试继续只使用内存数据库。
