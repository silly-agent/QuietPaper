# Quiet Paper MVP 设计

## 产品边界

Quiet Paper 是 macOS 本地优先的项目备忘录。内容可直接放在项目下，也可按“项目 / 模块 / 笔记”三级组织；笔记正文以 Markdown 原文持久化，可混合文字、标题、列表、代码块、JSON 与图片。编辑、保存、全文搜索不依赖网络。AI 只在用户主动提问时读取检索命中的少量片段，并始终返回来源路径。

本实现以 PRD v1.0 为设计基线，采用自适应的 macOS 分栏结构：项目直属文件使用“项目树 / 编辑器”两栏，选中模块时才加入中间文件列表并形成三栏。左上角创建入口只新建项目；文件与模块必须从具体项目的菜单创建，避免子项落入错误项目。界面使用系统材料与语义色，自动适配浅色和深色模式。

项目行单击只负责选择，双击负责展开或折叠，折叠箭头始终独立响应。重复选择当前项目、模块或文件不会重新读取数据库；侧栏尺寸变化也不会触发编辑器全文序列化，从而保证快速点击和侧栏开合保持流畅。

主题采用小巧、克制的固定字号体系：正文 13.5pt，列表主标题 12pt，辅助文字 10.5-11pt，编辑器标题 24pt。笔记默认进入编辑态；标题栏以铅笔和眼睛两个图标切换编辑/预览，减少文字控件和视觉噪音。

编辑器正文增加 5pt 行间距和段落间距；标题、列表、引用、代码与 JSON 格式化命令均优先作用于当前选区，没有选区时再作用于当前行或整篇文档。列表行的悬浮态与选中态共用同一背景范围和圆角。

内容区分隔线统一使用 0.5pt、约 4% 不透明度的 hairline；笔记列表不显示逐行分隔线，代码块边框同样保持低对比度，只保留必要的栏间结构边界。

## 技术方案

- Swift 6 + SwiftUI，最低 macOS 13。
- SQLite 直接持久化，启用 WAL、外键与 FTS5；Markdown 正文是唯一可信源。
- `WorkspaceDatabase` 封装迁移、事务和查询，视图不接触 SQL。
- `AppModel` 负责选择状态、草稿、600ms 合并自动保存、搜索和删除恢复。
- Markdown 阅读器解析常见块级结构；代码块保留原文并支持独立复制。
- 截图、浏览器复制的位图和 Finder 图片文件均可直接粘贴到编辑区；图片进入应用附件目录，编辑态在光标位置显示内联图片，底层仍以稳定的相对 Markdown 引用保存。
- `AIProvider` 为可替换协议；MVP 内置本地检索式实现，不发送任何数据。

## 数据流与失败处理

编辑器每次变化先更新内存草稿，再刷新延迟保存任务。切换笔记、窗口失焦和退出前强制保存。一次保存事务同时更新 `notes` 与 `notes_fts`；失败时保留草稿并显示重试入口。

删除采用软删除，并对项目和模块向下级联。最近删除可恢复或永久清理；永久删除笔记时同步清理附件目录。FTS 查询失败时使用标题与正文 `LIKE` 回退，核心编辑能力不受影响。

## 验证

- 数据库单元测试覆盖层级 CRUD、软删除/恢复、Markdown 原文和搜索索引。
- Markdown 解析测试覆盖标题、列表、代码块与未闭合围栏。
- 编辑器挂载测试覆盖中文输入、图片间文字、内联图片、选区工具栏、JSON 格式化、剪贴板位图和复制的图片文件；自动保存测试覆盖连续输入期间的草稿与数据库一致性。
- 完整执行 `swift test` 和 release 构建。
- 启动真实应用并截图检查三栏布局、浅/深色适配、笔记预览和代码块。
