# 模块一键导出设计

## 目标

在项目侧栏的项目与模块右键菜单中增加“一键导出”。用户选择后先决定导出形式：将范围内所有文件合并成一个 Markdown 文件，或将每个文件分别生成为 Markdown 并打包成 ZIP。

## 行为

- 合并导出按模块文件的稳定顺序生成文档，以模块名作为一级标题、文件名作为二级标题。
- 项目合并导出以项目名作为一级标题；项目根目录文件使用二级标题，子模块使用二级标题、模块文件使用三级标题。
- 项目 ZIP 在顶层保存项目根目录文件，并为每个子模块建立文件夹，空模块也会保留。
- 普通 Markdown 保留原文；HTTP 请求和数据库连接以带类型说明的 JSON 代码块写入，避免原始 JSON 破坏 Markdown 排版。
- 分开导出时，每个文件生成独立 `.md`。文件名会移除跨平台非法字符，并用数字后缀解决重名。
- ZIP 使用 macOS 自带的 `ditto` 在临时目录中生成，不增加网络或第三方依赖；成功后才移动到用户选择的位置。
- 导出前强制保存当前编辑中的文件。取消提示或保存面板时不写入任何文件，失败信息沿用应用现有错误提示。

## 验证

使用内存数据库和临时目录验证合并结构、非 Markdown 文件包装、文件名清理、重名处理以及 ZIP 文件生成。全程不读取、清空或重置用户数据库。
